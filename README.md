# 📊 Python Expense Tracker

> 💰 Track your income, expenses, and balance in one simple app.

**Python Expense Tracker** is a desktop application built with
**Python and Tkinter** that helps you keep track of your
daily financial transactions.

You can add income and expenses, organize them by category,
view your current balance, and delete transactions when needed.

---

## ✨ Features

- 💰 Add income
- 💸 Add expenses
- 📂 Add categories
- 📝 Add descriptions
- 📅 Automatic date recording
- 📈 Total income calculation
- 📉 Total expense calculation
- 💵 Current balance
- 🗑️ Delete transactions
- 🧹 Clear all transactions
- 💾 Automatic data saving
- 🔄 Data remains after restarting the app
- 🖥️ Clean dark-themed GUI
- 📦 No external libraries required
